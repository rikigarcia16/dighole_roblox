# CONTENT_STUDIO · Bottomless Games

Estudio de vídeo cortos de **The Hole Never Ends** (Roblox) para Instagram Reels y YouTube Shorts.
Sustituye la forma de trabajar anterior (plantilla única + frase encima) por **series con identidad propia**,
**tomas grabadas a propósito** en Roblox Studio y **8 familias de edición** con ritmo y sonido distintos.

| Carpeta | Contenido |
|---|---|
| `ANALYTICS/` | Revisión de lo publicado, métricas reales y plantilla para registrar resultados |
| `IDEAS/` | 10 series y 60 conceptos |
| `SCRIPTS/` | 20 guiones completos (plano a plano, con sonido y texto) |
| `STORYBOARDS/` | Hojas de fotogramas de cada vídeo producido |
| `RAW_GAMEPLAY/` | Índice de las tomas grabadas para este estudio (los fotogramas están en `MARKETING_ASSETS/10_RAW_GAMEPLAY/clips`) |
| `AUDIO/` | Biblioteca de sonido y música originales (generada por código, sin derechos de terceros) |
| `MOTION_GRAPHICS/` | Identidad visual: tipografía, subtítulos, transiciones, elementos gráficos |
| `EDITABLE_PROJECTS/` | Motor de edición v2 (`engine/`) y un proyecto por vídeo (`videos/`) |
| `FINAL_REELS/` · `FINAL_SHORTS/` | Exportaciones finales por plataforma |
| `THUMBNAILS/` | Portadas |
| `PUBLISHING_CALENDAR/` | Calendario y textos de publicación (pendiente de tu aprobación) |
| `INVENTARIO.md` | Estado de cada vídeo: IDEA → GUIÓN → EN PRODUCCIÓN → RENDERIZADO → REVISADO → LISTO → PUBLICADO |

Nada de este estudio se publica sin tu autorización.
